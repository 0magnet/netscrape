A site, fetched by a browser written in Go

This page was fetched by netscrape — the chrome above is a Go/wasm program drawing DOM through syscall/js, and this page is rendered into a sandboxed iframe with its stylesheet inlined by the transcoder.

The stylesheet that colours this page arrived as a separate request, relayed out of the sandbox and back in as a <style> element. The image below came back as a data: URI the same way.
