netscrape — a web browser written in Go and WebAssembly

The whole browser chrome is a Go program compiled to wasm: tab strip, address bar, back and forward history, and a transcoder that inlines a fetched page's stylesheet and relays its images back as data: URIs before rendering into a sandboxed iframe.

A static page can only fetch its own origin, so this demo browses a small sample site served beside it and says so plainly for anything else. That limit belongs to the transport, not to the browser — the same seam dials the dmsg mesh in Skywire's wasm visor, and in shipyard it reaches a Go server running in the next tab.

Source code: github.com/0magnet/netscrape. More Go and WebAssembly projects: magnetosphere.net/software.
